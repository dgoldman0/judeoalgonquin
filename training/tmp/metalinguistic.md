## Key Phrases for Explanations

| English | Judeo-Algonquin |
|---------|-----------------|
| "the prefix נֶ- shows 'we'" | קַדְמָא נֶ־ מַרְאֶה 'אֲנַחְנוּ' |
| "this word is Algonquian" | הַמִּלָּה הַזֹּאת אַלְגוֹנְקְוִינִית |
| "this word is Hebrew" | הַמִּלָּה הַזֹּאת עִבְרִית |
| "the suffix -ink means 'at/in'" | אַחְרָא -ינְק פֵּירוּשׁוֹ 'בְּ/עַל' |
| "translate to English as..." | לְתַרְגֵּם לְאַנְגְּלִית כְּ... |
| "the verb means..." | הַפֹּעֲלָא פֵּירוּשׁוֹ... |
| "this is narrative chain" | זֶה שַׁרְשֶׁרֶת סִפּוּר |
| "wayyiqtol pushes forward" | וַיִּ־ דּוֹחֵף קָדִימָה |
| "יוֹ is the main actor" | יוֹ הוּא הַפּוֹעֵל הָרָאשִׁי |
| "יוֹוָא is the other one" | יוֹוָא הוּא הָאַחֵר |

## Template Structures for Explanations

### For verbs with נֶ- prefix:
```
קַדְמָא נֶ־ מַרְאֶה 'אֲנַחְנוּ'. הַפֹּעֲלָא [X] פֵּירוּשׁוֹ '[English]'. לְתַרְגֵּם: "we [verb]"
```

### For locatives:
```
אַחְרָא -ינְק מַרְאֶה מָקוֹם. [noun]-ינְק = 'at/in the [noun]'
```

### For wayyiqtol:
```
וַיִּ־ דּוֹחֵף הַסִּפּוּר קָדִימָה. פֵּירוּשׁוֹ 'and then [action]'
```

### For prox/obv:
```
יוֹ הוּא הַפּוֹעֵל הָרָאשִׁי. יוֹוָא הוּא הָאַחֵר. לְתַרְגֵּם יוֹ כְּ 'this one', יוֹוָא כְּ 'that one'
```
